# SAAFAAR image provenance
The project contains original destination/public brand images fetched by scripts/build_assets.py from user-controlled saafaar.in:
- assets/img/meghalaya-waterfall.webp ← /assets/img/meghalaya-waterfall-1600.webp
- assets/img/meghalaya-hills.webp ← /assets/img/meghalaya-hills-waterfalls-1600.webp
- assets/img/arunachal-mountains.webp ← /assets/img/arunachal-mountain-gateway-1024.webp
- assets/img/kaziranga-rhino.webp ← /assets/img/kaziranga-rhino-1600.webp
- assets/img/saafaar-logo.webp ← /assets/logo/saafaar-logo-optimized.webp

The supplied large historic vehicle/destination ZIPs are NOT accessible to the GitHub build, so all vehicle photos still require mapping and explicit approval. The live-site imagery is not relabelled as vehicle photos. New administrator-approved vehicle photos can be uploaded from /admin/.
Original wordmark is displayed in the header/footer. PNG icons are locally generated minimal SAAFAAR monogram derivatives.
